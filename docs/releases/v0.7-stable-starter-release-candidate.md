# v0.7 — Stable Starter Release Candidate

## Status

**Draft.** This candidate is rebased onto the current v0.6 foundation and still requires a fresh full GitHub Actions run plus native file:// sign-off in an unrestricted browser before it can be merged or tagged.

## Included

- Crystal Mines is the fifth bundled example.
- Crystal Mines keeps all theme identity under examples/crystal-mines/ and adds no theme code to js/engine/.
- The full smoke runner includes the Crystal Mines proof.
- Future-version, malformed, and wrong-example saves are no longer normalized into the active slot. They remain untouched and can be exported as blocked backups.
- Browser-storage failures are handled as session-only play instead of aborting startup.
- The release checklist now reflects the complete current smoke gate and native browser requirements.

## Validation Required

1. GitHub Actions must pass node run_smokes.mjs and report 14/14 scripts passed on this rebased head.
2. From a clean clone or source archive, open index.html directly through file:// in an unrestricted Chrome, Edge, Firefox, or Safari browser.
3. Load all five examples, reload each save, fight, loot, equip, export, import a compatible save, confirm incompatible-save protection, and reset.
4. Record the completion in this note or the pull request before marking the candidate ready.

## Boundaries

v0.7 remains a clone-first browser RPG starter. It does not add remote content packs, package publishing, server persistence, multiplayer, or a third-party mutation-plugin runtime.
